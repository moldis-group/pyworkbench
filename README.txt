Python Data Analysis Workbench — Local Workspace Edition
=========================================================

Files

index.html

What is new
-----------
1. Ace editor with Python syntax highlighting and line numbers.
2. Autosaved draft and named sessions.
3. Save/Open/Download Python scripts.
4. Optional real local workspace selected with the browser folder picker.
5. IndexedDB browser storage remains as a fallback.

Local workspace layout
----------------------
When you click "Choose local workspace" and select a folder, the workbench creates:

  data/       uploaded/input files
  scripts/    Python scripts saved with named sessions
  sessions/   session JSON files and _autosave.json
  output/     new files generated by Python

The selected folder is a real folder on the laptop and is visible in Finder/File Explorer.
For security, the browser does not expose or accept arbitrary absolute path strings; the folder
must be selected using the system folder picker.

How synchronization works
-------------------------
Pyodide still executes inside the browser and uses /data internally.
When a local workspace is connected:

- local data/ and output/ files are mirrored into Pyodide /data
- uploaded files are written to local data/
- named sessions are written to local sessions/
- corresponding Python scripts are written to local scripts/
- autosave is written to local sessions/_autosave.json
- files created or modified by a Python run are synchronized back to the local workspace
  (new files go to output/; existing input files retain their data/ origin)

Browser compatibility
---------------------
Direct folder access requires the File System Access API. It is best supported by Chromium-based
browsers such as Chrome and Edge and requires a secure context (GitHub Pages via HTTPS is suitable).
If unsupported or permission is not granted, the workbench continues using IndexedDB browser storage.

Folder permissions
------------------
The browser may ask you to reconnect to a previously selected folder after a restart or new browser
session. Use the Reconnect button. The workbench remembers the directory handle when the browser permits it.

Keyboard shortcuts
------------------
Ctrl/Cmd + Enter       Run Python
Ctrl/Cmd + S           Save current named session
Ctrl/Cmd + Shift + S   Save As
Ctrl/Cmd + F           Find in editor

Resizable and floating editor
-----------------------------
The Ace editor can now be resized interactively by dragging its lower-right corner.
Additional controls provide:

  Small        350 px editor height
  Large        700 px editor height
  Full screen  editor fills the browser window
  Float        editor becomes a draggable, independently resizable window

In Float mode, drag the "Python editor" title bar to move the editor and drag the lower-right
corner to resize it. Click Dock to return it to the normal page layout.
